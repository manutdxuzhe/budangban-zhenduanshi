## 这是什么

不是辞职测试，不是填表打分，也不是机器替你下结论。

它用一套**问诊式对话**，帮你把"走不走"这件事的账和局看清楚。

---

## 我怎么看你：从症状往根上挖（四层框架）

一个人说"我不想上班了"，背后其实是四层东西叠在一起。我从浅往深问，一层一层看：

| 层 | 看什么 | 为什么这么排 |
|---|---|---|
| **症状层** | 想走的直接诱因：加班、通勤、工资、内耗、行业下行…… | 最表层。它们是**加速器**，通常不是根——换个地方，同样的诱因很可能再来一遍 |
| **价值层** | 离开现在这个平台，你有哪些**不依赖平台**的本事 | 不盯岗位技能——会聊天、会张罗、能把烂摊子理清楚，生活里练出来的也算；这些本事换个地方人家也认（它需要方向才有答案，所以排在方向层上面） |
| **方向层** | 想去哪、以什么角色、**这条路验证过没有** | 最不能含糊的一层。说得清"不想要什么"≠有方向；有方向但从没试过，也还不能算数。**这层决定了上一层（价值层）里哪些本事才算数**——同一个本领，冲着不同方向，值钱程度完全不同。 |
| **重心层** | 你最在乎什么、愿意放弃什么 | 最深的一层，也是所有判断的最终依据。钱、家庭、成长、自由——哪个压秤，只有你说了算 |

另外，**钱的事单独算一栏，不在这四层里**：存款能撑几个月、家里还有没有别的进账、赔偿多少。它们不决定你"该不该走"，但决定你"走得起、走不起"。

> 这四层从上到下，越往下越接近根。
> 很多人卡住，是因为一直在最上面那层打转——换了三份工作，还是同一个困局。

## 我的判断靠什么：13 本书站在四个问题上（融合 13 本经典）

一个人纠结辞不辞职，说到底是卡在 4 个问题上。这 13 本经典，就分别站在这 4 个问题上——每一个判断都有书打底，不是拍脑袋：

| 维度 | 关注点 | 参考书籍 |
|---|---|---|
| **走不走** | 眼前的烦心事具体是啥、有没有可能解决、这份工作值不值得接着干、要走的话什么时候最合适 | 《决断力》《适时退出》《毫无意义的工作》《要钱还是要生活》 |
| **往哪走** | 是换工作还是换行业还是创业、有没有具体方向、这个方向验证过没有 | 《如何找到想做的事》《斯坦福人生设计课》 |
| **能走吗** | 离开平台你还有哪些能力、和你想去的地方适不适配、这些能力在市场上值多少钱 | 《优秀到不能被忽视》《终身成长》《工资的真相》 |
| **怎么走** | 能力怎么提升、工作怎么找、要是创业得准备什么 | 《你的降落伞是什么颜色》《转行》《纳瓦尔宝典》《反脆弱》 |

> 从"想走"到"真走"，**走不走 → 往哪走 → 能走吗 → 怎么走**，每一步都有书撑着。

## 它怎么帮你

1. **从一个具体时刻切入** —— "最近一次强烈想走，是哪天、因为啥？"（人讲故事时给的信息，比分析时多得多）
2. **收齐事实 + 两道补问** —— 会不会漏了"第三条路"？有没有我压根没问到的？
3. **给你一张四层对照表** —— 关注什么 / 你的情况，哪里空着你一眼就看见
4. **给判断 + 一个最值得先做的小动作** —— 我说我的看法，但绝不替你按下"走"或"留"那个键

**两道铁律**：
- 钱的事（存款、赔偿、支出）只让你自己算、给个数字结论，**绝不扒你明细**
- 我给判断，**但决定权永远在你**

## 关于"诊断"

这里的"诊断"是**处境和决策维度的比喻**，不是医学或心理诊断。

如果聊到长期失眠、持续耗竭、撑不住——那一步该找专业的人，工具会建议你去求援，不替你下健康结论。
