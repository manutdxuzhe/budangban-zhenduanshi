# 不想上班诊断室 · 一个帮你算清「走不走」的 AI 问诊 Skill

> 适用于 **WorkBuddy / Trae / 豆包 / Codex** 等支持 Skill 的 AI 客户端

每天睁眼就不想上班？纠结「要不要辞职」想了半年也没个结果？

这个 skill **不替你决定走还是留**，而是通过一次一次地问诊、反复地聊，帮你把「走不走」这笔账算清楚——一直问到你真正想明白。

- 📚 蒸馏了 **13 本**职业发展经典
- 🧭 一套从「症状层」一直挖到「重心层」的**四层框架**
- 💬 一般 **6–8 轮**对话，给你一份有书撑腰的判断
- 🔑 最终决定权，**永远在你手上**

---

## 它怎么帮你？

| 层 | 看什么 |
|---|---|
| 症状层 | 直接诱因（加班 / 人际 / 工资…大多只是「加速器」） |
| 价值层 | 你有哪些不依赖平台的能力（生活里练的也算） |
| 方向层 | 离开后去哪、以什么角色、这条路验证过没有 |
| 重心层 | 你最在乎什么、肯放弃什么 |
| 钱 | 单独一栏「现实条件」，决定走得起走不起 |

13 本书按 **走不走 / 往哪走 / 能不能走 / 怎么走** 四个维度组织。遇到对应问题，它会从中提取观点、综合给你建议——不是某一本书的单一视角，而是 13 本的综合，思考更全面。

## 怎么装（3 种方式）

**方式一：最省事（推荐）**
把本仓库里的 `zheshifu-skill` 文件夹直接丢给任意 AI Agent，说「帮我把这个 skill 装到 skills 目录里」，它会自己搞定。WorkBuddy / Trae / 豆包 / Codex 均已验证可用。

**方式二：手动**
1. 点仓库右上角 `Code → Download ZIP` 下载整个仓库并解压（或用 `git clone`）
2. 找到里面的 `zheshifu-skill` 文件夹，整个放进 `C:\Users\你的用户名\.workbuddy\skills\`（其它客户端路径类似）
3. 重启客户端即可生效

> 想要打包好的 zip 安装包？见本仓库 **Releases**（如有）；或直接用上面的文件夹方式，效果一样。

**方式三：WorkBuddy 技能市场**
若已上架，直接在客户端搜「不想上班诊断室」一键安装。
