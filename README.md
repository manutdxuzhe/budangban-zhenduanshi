# 不想上班诊断室 · 一个帮你算清「走不走」的 AI 问诊 Skill

> 适用于 **WorkBuddy / Trae / 豆包 / Codex** 等支持 Skill 的 AI 客户端

每天睁眼就不想上班？纠结「要不要辞职」想了半年也没个结果？

这个 skill **不替你决定走还是留**，而是通过一次一次地问诊、反复地聊，帮你把「走不走」这笔账算清楚——一直问到你真正想明白。

- 📚 蒸馏了 **13 本**职业发展经典
- 🧭 一套从「症状层」一直挖到「重心层」的**四层框架**
- 💬 一般 **6–8 轮**对话，给你一份有书撑腰的判断
- 🔑 最终决定权，**永远在你手上**

---

## 它怎么帮你？

| 层 | 看什么 |
|---|---|
| 症状层 | 直接诱因（加班 / 人际 / 工资…大多只是「加速器」） |
| 价值层 | 你有哪些不依赖平台的能力（生活里练的也算） |
| 方向层 | 离开后去哪、以什么角色、这条路验证过没有 |
| 重心层 | 你最在乎什么、肯放弃什么 |
| 钱 | 单独一栏「现实条件」，决定走得起走不起 |

13 本书按 **走不走 / 往哪走 / 能不能走 / 怎么走** 四个维度组织。遇到对应问题，它会从中提取观点、综合给你建议——不是某一本书的单一视角，而是 13 本的综合，思考更全面。
